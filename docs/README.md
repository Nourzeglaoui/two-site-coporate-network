\# Two-site-corporate-network 



As my second project I wanted to apply the networking skills I learned by taking CCNA courses in Uni by creating a secure two-site corporate network that simulates a real world environment.

Headquarters and a remote branch connected by a point-to-point WAN link.



\# Goals 

\-Multi area OSPF routing.

\-VLAN segmentation with inter VLAN routing on Layer 3 switches.

\-Guest VLAN isolated from the servers and management via access control lists.

\-SSH-only device administration with Telnet disabled.



\## Note on credentials

This is a lab. All passwords in the configs are throwaway values and have

been replaced with placeholders where they appear.
